# Edge AI SoC - AMBA 3 APB Peripheral Subsystem

## Overview
This repository contains the design, simulation, and integration of AMBA 3 APB-compliant peripheral IP cores (GPIO and Timer) for an Edge AI SoC project.

## Project Structure
```text
edgeai_soc/
├── apb_gpio/          # APB GPIO IP Core Design
├── apb_timer/         # APB Timer IP Core Design
├── apb_subsystem/     # Integrated Subsystem Top Wrapper & Testbench
└── documentation/     # Simulation Waveforms & Verification Reports
